# Alkinda · alkinda.com

Personal app platform on **Hostinger Node.js** + **MySQL**.

- `https://alkinda.com/` — Alkinda home (app launcher)
- `https://alkinda.com/lineage/*` — **Lineage** (first app)
- `/api/health` — Node + DB status

## Local

```bash
npm install
cp .env.example .env.local
npm run dev
```
